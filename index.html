AI Tools

Инструменты искусственного интеллекта, которые мы используем в команде

GitHub Copilot

AI Agent

AI-помощник для написания кода прямо в редакторе. Автодополнение, генерация функций и документации.

Code Completion Chat PR Review

Cursor

AI Agent / IDE

AI-первый редактор кода на базе VS Code. Глубокая интеграция с LLM для редактирования и генерации кода.

Multi-file Edit Composer Codebase Context

MCP Servers

Протокол для подключения AI к внешним источникам данных и инструментам. Расширяет возможности агентов.
